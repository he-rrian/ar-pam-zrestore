第 4 轮训练结果（mouse4，60 epoch，2026-11-06 05:43–06:43）—— 目前最好
====================================================================

【相对第 3 轮改了什么（换范式）】
  1. L2 空间损失（替代 Charbonnier/L1）。原因：L1 的最优解是中位数，
     对"把 RL 结果磨平"是奖励的；L2 对峰值/振铃对称惩罚。
  2. 保留 RL 物理先验：6 通道输入（5 帧 + RL 反卷积），
     残差基底改成 RL 通道： out = relu(RL + head(h))，初始输出就是 RL。
  3. RL 迭代 25 → 15（提速），60 epoch。

【结果（best_fwhm.pth = 第 21 epoch 快照；80 帧、7237 个孤立峰）】
  FWHM raw 中位 7.22 px → enh 4.36 px   （1.66x，86.0% 的峰变窄）
  等价物理尺度：15.2 μm → 9.2 μm
  按深度：z100-200 1.77x / z200-320 1.58x / z320-457 1.51x（三层都变锐，没有深层退化）
  空白区 ghost 均值 0.0004（极干净）
  能量比 1.31x
  前向一致性残差 0.555（偏高，见下）
  饱和（>1.2）< 0.1%

【与零训练基线对比】
  包络 RL（25 it）：5.0 px / 10.5 μm（1.63x）
  本网络：        4.36 px / 9.2 μm（1.66x）  → 已打过 RL 基线
  FWHM 及格线（≤5.0 px）达成。

【已知问题】
  1. 前向一致性残差 0.555 > 0.4：RL 基底的振铃被网络部分保留，
     输出再经 A(z)·PSF 模糊后与原始声光不完全吻合。
     图上看不出明显伪影，但这是下一步要压的指标。
  2. **训练后期会变糊**：val 最优（epoch 60）的 FWHM 是 5.35 px，
     epoch 21 才是 4.36 px。说明"伪验证集 loss"与"真实 Z 清晰度"不同向。
     下一轮应保存每 5 epoch 的 checkpoint，并用真实数据 FWHM 选模型。
  3. evaluate_layers 的 density–depth 仍跑不出来（0 个有效 Y）：
     457 层窗口里表面常在 100~400 层，留给"表面下 320 层"的空间不足；
     要么用宽 slab，要么把 need 降到 40~60 并接受更浅的统计深度。
  4. 表面回波仍被保留（enhanced 里 0.4 mm 处的亮弧），这是物理信号，未做抑制。

【下一步建议】
  * 每 5 epoch 存 checkpoint，用真实 FWHM 做早停（预计能稳定在 4.3~4.5 px）。
  * 用 L2 + 物理权重 2.0 微调 8~10 epoch，把前向残差从 0.55 压到 <0.45。
  * 若仍偏高：把 RL 的振铃用 TV/双边先平滑一点再作为基底。
