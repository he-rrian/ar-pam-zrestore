第 1 轮训练结果（mouse4，60 epoch，2026-11-06 03:00–03:35）
============================================================

【配置】
  输入：声光 5 帧（±20/±10 μm），镜像纠偏 + RF 20:340 + 整卷 gain，无上限 clip
  目标：光片，按 <20 μm 软加权（strength 3.0, floor 0.15）
  损失：Charbonnier×权重 + 均值 + 梯度0.2 + 拉普拉斯0.05 + 物理前向1.0
        + 空白区0.5 + TV0.01 + thin 超额 0.1
  表面回波：30% 概率叠加（域随机化）

【结果（evaluate_real，80 帧、7519 个孤立峰）】
  FWHM raw 中位 7.34 px → enh 9.82 px   （收窄 0.75x，反而变宽）
  真正变窄的峰占比 26.8%
  能量比 1.69x
  前向一致性残差 0.402
  空白区 ghost 均值 0.0014（很好）
  饱和（>1.2）0.13%
  按深度：z100-200 0.73x / z200-320 0.75x / z320-457 0.89x

【问题】
  1. 网络没学会反卷积，学成了"提亮 + 平滑"。
     隔离实验（无噪 clean 输入、已知 target）：
       input  |dz|=0.00072   pred |dz|=0.00133   target |dz|=0.00346
     即 pred 只恢复了 target 轴向梯度的 38%。
  2. 主因判断：thin 惩罚以 clean（已模糊）为基准，
     relu(|thin(pred)|-|thin(clean)|) 等于"惩罚比模糊图更锐的部分"，
     与去卷积目标直接冲突；λ=0.1 足以把网络推向平滑。
  3. 次因：尺度软加权 strength=3.0/floor=0.15 把血管边缘也降到 0.86，
     边缘监督被削弱；60 epoch 对零初始化残差头可能偏少。
  4. 表面回波被放大（XZ 图上表面弧更亮），说明"亮区放大"是网络的主要行为。
  5. evaluate_layers 在 457 网格上 need=320 过严，导致 0 个有效 Y、density-depth 为 nan。

【第 2 轮的改法】
  * LAM_THIN = 0（先完全移除，验证它是不是元凶）
  * THIN_WEIGHT_STRENGTH 3.0 → 1.0，FLOOR 0.15 → 0.40（边缘恢复到 0.95 左右）
  * LAM_GRAD 0.2 → 0.5（强化边缘监督）
  * LR 3e-4 → 4e-4，epochs 60 → 80
  * evaluate_layers 的 need 改为 min(out_z,120)，让分层统计能跑出来
